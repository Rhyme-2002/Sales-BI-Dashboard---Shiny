# 📊 Sales & BI Dashboard — Shiny

An interactive **Sales & Business Intelligence Dashboard** built with **R Shiny** for analyzing sales performance, revenue, profit, products, categories, regions, and salespeople.

## 🚀 Live Demo

🌐 **Live Dashboard:**
https://rhyme-sales-bi-dashboard.share.connect.posit.cloud/

💻 **GitHub Repository:**
https://github.com/Rhyme-2002/Sales-BI-Dashboard---Shiny

## ✨ Features

* 📊 Sales and profit KPIs
* 📈 Revenue trend analysis
* 🌎 Revenue by region
* 🏷️ Revenue by category
* 📦 Top 10 products
* 👨‍💼 Salesperson performance
* 🔎 Interactive data explorer
* 📂 CSV and Excel file upload
* 🎛️ Date, region, category, and salesperson filters
* 📥 CSV data export
* 📄 PDF, HTML, and PNG report downloads

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/Rhyme-2002/Sales-BI-Dashboard---Shiny.git
```

Install the required packages:

```r
install.packages(c(
  "shiny",
  "shinydashboard",
  "dplyr",
  "ggplot2",
  "DT",
  "readxl",
  "scales",
  "lubridate",
  "htmltools",
  "knitr",
  "webshot2"
))
```

Run the app:

```r
shiny::runApp()
```
